# Global Time Viewer (GTV)

**여러 지역의 시각을 한 표에서 비교하고, 날짜·시간을 조정하거나 계산할 수 있는 Chrome 확장 프로그램입니다.** 확장 아이콘을 누르면 새 탭에서 열립니다.

현재 버전은 **v3.16.9**이고, 현재 안정 버전은 **v3.16.1 · 5차 안정 버전**입니다. 안정 버전은 웹 스토어 제출 기준으로 고정한 버전이며, 안정 버전 지정과 실제 웹 스토어 제출·게시는 별개입니다.

## 할 수 있는 일

- 여러 지역의 현재 시각을 한 표에서 비교합니다(실시간).
- 기준 날짜·시각을 바꿔 각 지역에서 그 순간이 몇 시인지 확인합니다(시간 변경).
- 시작·끝이 있는 여러 시간 구간을 나란히 비교합니다(연속 시간 변경).
- 지정한 날짜의 여러 시각을 시간대별 표와 타임라인으로 봅니다(고정 시간).
- 기간·날짜 이동·카운트다운·시간 형식 변환을 계산합니다(계산기 도구).
- 표를 텍스트로 복사하거나 이미지로 저장하고, 표기·복사 양식을 정합니다.
- 시간대를 그룹·보조 그룹으로 묶고 설정을 파일로 내보내거나 가져옵니다.
- 한국어·영어, 다크·라이트 테마, 50~200% 화면 크기를 지원합니다.

## 설치하기

### Chrome 웹 스토어에서 설치 (권장)

[Chrome 웹 스토어의 Global Time Viewer 페이지](https://chromewebstore.google.com/detail/ojmkgfaeececindhbegihnonpndkbnho)에서 설치합니다. 스토어 설치본은 자동으로 업데이트됩니다. 스토어에는 심사를 거친 안정 버전만 올리므로 이 저장소의 현재 버전보다 늦을 수 있습니다.

### 배포 ZIP으로 직접 설치

1. 배포 파일 `gtv-v버전.zip`의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 압축을 푼 폴더 중 `manifest.json` 파일이 있는 폴더를 선택합니다.

직접 설치한 경우에는 자동 업데이트가 되지 않습니다. 소스에서 빌드하려면 [개발자 가이드](docs/developer-guide.md)의 "개발 환경·검증·배포"를 따르세요.

## 알아두면 좋은 동작

| 항목 | 동작 |
| --- | --- |
| 설정 저장 | 그룹·시간대·양식 설정은 이 확장 프로그램 전용 브라우저 저장공간(localStorage)에 자동으로 보관됩니다. 확장 프로그램을 제거하거나 브라우저 데이터를 지우면 사라질 수 있으므로 `전체 내보내기`로 백업하세요. |
| 커스텀 시간대 | 입력한 고정 UTC 시차만 사용하며 서머타임을 따르지 않습니다. 서머타임이 필요하면 목록의 표준 시간대를 고르세요. |
| 서머타임 표시 | 서머타임 기간인 시각 옆에 `DST`가 표시되며, 시각이 여러 개면 시각마다 따로 판단합니다. 텍스트 복사와 저장 이미지에도 들어가고, `표기 / 복사 양식`의 시간 항목 `서머타임`으로 켜고 끌 수 있습니다. |
| 서머타임 경계 입력 | 서머타임이 시작되며 건너뛰는 시각(예: 뉴욕 02:30)은 건너뛴 만큼 뒤(03:30)로 맞추고 안내하며, 끝나며 두 번 있는 시각은 첫 번째(서머타임) 시각으로 해석합니다. |
| 가져오기 실패 | 형식이 맞지 않는 파일은 거부하며 기존 설정은 그대로 둡니다. |
