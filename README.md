# Global Time Viewer v3.8.1

## 최근 업데이트 (v3.8.1)
- 시간 변경 탭 시간 자동 흐름 버그 수정 (비실시간 모드 동기화 보정)
- 연속 시간 변경 탭 테이블 컬럼 너비 최적화 (가독성 향상)
- 전체 프로젝트 버전 동기화 (v3.8.1)

## 주요 기능
- 실시간 시간대 비교 및 다국어 이름 표시 지원 (i18n)
- 시간 편집 모드 (단일 또는 이중 슬롯)
- 범위 블록/하위 그룹이 있는 연속 시간 편집 모드 (구간 표)
- 실시간/시간 편집을 위한 타임라인 뷰 (드래그 가이드 지원)
- 유연한 표시/복사 형식 제어 (구간 복사 등)
- 계산기 도구:
  - 시간 단위 변환기
  - 기간 계산기
  - 날짜 이동 계산기
  - 카운트다운
  - Unix 타임스탬프 변환기
- 설정 내보내기/가져오기 및 그룹/하위 그룹 내보내기/가져오기
- 표/구간 뷰를 위한 이미지 내보내기

## 실행 방법
1. 브라우저에서 `index.html`을 열거나,
2. `chrome://extensions`를 통해 폴더를 Chrome 확장 프로그램으로 로드합니다 (개발자 모드).

## 데이터 저장
본 앱은 사용자 데이터를 안전하게 보존하기 위해 다음 저장소 아키텍처를 사용합니다:

1. **Chrome 확장 프로그램 환경**: 브라우저의 전용 비동기 저장소인 `chrome.storage.local`을 사용하여 브라우저 종료 시에도 데이터를 안전하게 유지하며, 대용량 데이터 저장 시 보안성이 강화되었습니다.
2. **웹/개발 환경 (Fallback)**: 확장 프로그램 환경이 아닐 경우 표준 `localStorage`를 사용하여 상태를 관리합니다.

### 주요 저장소 키 (Storage Keys)
- **데이터 통합 관리**: `GTV_v323_Data` (그룹, 타임존, 구간 정보 등)
- **사용자 개인화 설정**:
  - 테마: `GTV_Theme`
  - 언어: `GTV_Lang`
  - UI 스케일: `GTV_UIScale`
