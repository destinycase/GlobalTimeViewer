## 직전 안정 버전 이후 추가·개선된 기능

항목 앞의 분류: **추가** 새 기능, **개선** 기존 기능의 개선(다른 기능과 합친 경우 포함), **수정** 제공하던 기능의 버그 수정, **제거** 제공하던 기능의 삭제.

### 서머타임(DST) 표시

- **개선** 서머타임 기간인 시각 옆에 `DST`를 표시합니다. 시작·끝처럼 시각이 여러 개면 시각마다 따로 판단하므로, 서머타임이 끝나는 날을 걸치는 구간도 정확히 보입니다. 지역 이름에는 더 이상 `[DST]`를 붙이지 않습니다.
- **개선** 시간 변경, 연속 시간 변경, 고정 시간 탭에 모두 적용되며, 고정 시간 탭은 고정 날짜를 기준으로 각 슬롯 시각에 표시합니다.
- **추가** 텍스트 복사와 이미지 저장에도 서머타임인 시각 뒤에 `DST`가 들어갑니다.
- **추가** `표기 / 복사 양식`의 시간 항목에 `서머타임`이 추가되어 표시와 복사에서 따로 켜고 끌 수 있습니다(기본 켜짐).
- **개선** 사용자 지정 시차, 시차 목록에서 고른 항목, UTC에는 표시하지 않습니다.

### 시간대 정확도

- **수정** 고정 시간 탭의 시간대 약어(예: PDT/PST)를 UTC 시차·`DST` 표시와 같은 고정 날짜 기준으로 표시합니다.
- **수정** 예전 버전(v3.11.1 이전)에서 서머타임 도시를 "PDT"·"PST" 같은 고정 시차로 추가한 항목을 설정을 불러오거나 가져올 때 그 도시의 서머타임 규칙을 따르도록 자동으로 바꿉니다. 이런 항목이 1년 중 절반 동안 실제 시각과 1시간 어긋나던 문제가 없어집니다. 시차 목록에서 직접 고른 항목은 그대로 둡니다.
