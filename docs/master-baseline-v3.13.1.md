## 직전 안정 버전 이후 추가·개선된 기능

항목 앞의 분류: **추가** 새 기능, **개선** 기존 기능의 개선(다른 기능과 합친 경우 포함), **수정** 제공하던 기능의 버그 수정, **제거** 제공하던 기능의 삭제.

### 시간 입력과 계산

- **수정** 서머타임이 바뀌기 직전 몇 시간 안의 시각을 입력해도 1시간 어긋나지 않고 입력한 시각 그대로 저장합니다.
- **수정** 시간 변경·연속 시간 변경·고정 시간의 날짜·시간 입력과 계산기가 0~99년 날짜(예: 0050-01-01)를 입력한 연도 그대로 받습니다. 앱 전체가 같은 날짜 검사 규칙을 씁니다.
- **수정** 계산기 기간 계산에서 UTC보다 늦은 시간대(미주 등)에서도 시작일·종료일 바꾸기가 날짜를 그대로 유지합니다.
- **수정** 끝이 시작보다 이른 기간의 길이를 정확하게 표시합니다.
- **수정** 브라우저가 지원하지 않는 시간대가 들어오면 잘못된 날짜 대신 UTC 기준으로 표시합니다.

### 고정 시간

- **개선** 타임라인에서 슬롯 표시선을 끄는 동안 시간대 표 전체를 다시 만들지 않고 바뀐 칸(시각, 낮/밤, 요일, 시차)만 고쳐 그려, 시간대와 슬롯이 많아도 끌기가 부드럽습니다.
- **수정** 슬롯 표시선을 끌어 옮기던 중 끌기가 취소되어도 옮긴 시각을 저장합니다.

### 저장과 가져오기

- **수정** 그룹·보조 그룹 가져오기에서 저장에 실패하면 기존 그룹을 그대로 유지합니다.
- **개선** 브라우저 저장 공간이 가득 차 설정을 저장하지 못하면 "저장 공간이 부족합니다" 알림을 표시합니다. 그 밖의 저장 실패는 일반 저장 실패 알림을 표시합니다.
