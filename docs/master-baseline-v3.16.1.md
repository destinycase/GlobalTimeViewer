## 직전 안정 버전 이후 추가·개선된 기능

항목 앞의 분류: **추가** 새 기능, **개선** 기존 기능의 개선(다른 기능과 합친 경우 포함), **수정** 제공하던 기능의 버그 수정, **제거** 제공하던 기능의 삭제.

### 설정과 도움말

- **개선** 사이드바 왼쪽 아래에는 도움말(❓)과 설정(⚙️) 아이콘 버튼만 둡니다.
- **개선** 설정 창에서 UI 크기·테마·언어를 바꾸고, 전체 설정을 내보내거나 가져오고, 설정만 초기화·전체 초기화를 합니다. 각 항목의 설명이 창 안에 보이며, 초기화를 확인하거나 가져오기에 성공하면 창이 닫힙니다.
- **추가** 도움말 창에서 시간대 추가, 그룹, 기능 탭, 시각 입력, 서머타임 표시, 복사·이미지 저장, 설정과 백업을 짧게 안내합니다(한국어·영어).
- **개선** 창은 닫기 버튼, 창 바깥 클릭, Esc로 닫습니다.

### 입력·확인 창

- **개선** 그룹·보조 그룹 추가와 이름 바꾸기, 고정 시간 슬롯 이름 바꾸기는 앱의 화면 안 입력 창으로 묻습니다.
- **개선** 설정만 초기화·전체 초기화, 그룹·보조 그룹 삭제는 앱의 화면 안 확인 창으로 묻습니다(처음 초점은 취소, 닫기·바깥 클릭·Esc는 취소).

### 그룹

- **수정** 왼쪽 기능 탭(실시간·시간 변경·연속 시간 변경·고정 시간)을 바꿔도 선택한 시간대 그룹이 그대로 유지됩니다.

### 화면 배치

- **수정** 연속 시간 변경 표의 시작·끝 시간 칸이 창 너비 1280px 이상에서 옆 칸과 겹치지 않습니다. 칸이 좁으면 요일·서머타임·달력 표시가 시각 아래 줄로 내려갑니다.
- **수정** 시간 변경 표는 1440px 이상에서 옆으로 넘치지 않습니다. 칸이 좁으면 요일·서머타임·달력 표시가 시각 아래 줄로 내려갑니다.
- **수정** 시간 포맷 변환기는 항목 이름을 입력칸 위에 두어 긴 값(RFC 2822, 사람이 읽기 쉬운 형식 등)이 잘리지 않습니다.
- **수정** 시간 조정 줄(시작 시간 조정·끝 시간 조정·구간 일괄)의 시간·일·주 버튼이 줄마다 같은 위치에 섭니다(다른 탭에서 시작하거나 화면 크기를 바꿔도 같음).

### 화면 모양

- **개선** 주요 버튼(그룹 추가 `+`, `목록`, `추가`)만 강조하고 나머지 버튼은 중립 회색, 삭제 버튼은 평소 은은한 붉은색입니다. 그룹·보조 그룹 탭 아이콘은 테두리 없이 표시합니다.
- **개선** 항목 사이 구분은 얇은 선, 큰 라벨은 차분한 색입니다. 옵션 체크박스는 켜짐/꺼짐 스위치 모양입니다.
- **개선** 타임라인의 낮·밤 칸 색을 부드럽게 바꾸고 표시선을 얇게 했습니다(끄는 영역은 그대로).
- **개선** 입력칸은 입력 중일 때만 파랗게 강조하고, 표의 세로선은 옅게, 시간대 선택 창 항목은 카드 모양입니다.
- **개선** 위쪽 그룹 탭의 높이를 줄였고, 사이드바 제목은 `Global Time Viewer`와 버전 두 줄입니다.
