## 직전 안정 버전 이후 추가·개선된 기능

항목 앞의 분류: **[추가]** 새 기능, **[개선]** 기존 기능의 개선(다른 기능과 합친 경우 포함), **[수정]** 제공하던 기능의 버그 수정, **[제거]** 제공하던 기능의 삭제.

### 시간대 관리 창

- **[개선]** 도구 줄 맨 앞의 `타임존 추가` `[목록]`을 `시간대` `[관리]`로, 창 이름을 `시간대 관리`로 바꿨습니다(영어: Timezones [Manage], Manage Timezones). `관리` 버튼은 그룹 추가(+) 버튼과 같은 밝기입니다.
- **[개선]** 창에 `그룹 목록` 탭을 더해 먼저 열리게 했습니다. 현재 그룹의 시간대를 표와 같은 순서로 보이며, 탭 이름 뒤에 개수가 보입니다.
  - 손잡이를 끌거나, 손잡이를 고른 뒤 위·아래 방향키로 순서를 바꿉니다.
  - `X`로 지웁니다. 맨 위 시간대는 지울 수 없습니다.
- **[개선]** `그룹 목록`의 맨 위 시간대가 기준 시간대입니다. 다른 행을 맨 위로 끌면 그 행이 기준이 되고 이전 기준은 바로 아래로 갑니다. 맨 위 행에만 `기준` 표시가 붙습니다. 기준 시간 선택은 그룹 설정 창에서 이곳으로 옮겼습니다.
- **[개선]** `시간대 프리셋`이나 `사용자 커스텀`에서 추가해도 창이 열려 있고, 추가했다는 안내가 뜹니다. `사용자 커스텀`은 추가 뒤 입력칸이 비워집니다.
- **[개선]** 창 바깥(어두운 영역)을 클릭해도 닫힙니다.
- **[개선]** 탭을 옮겨 내용 길이가 바뀌어도 창 위쪽 위치는 그대로이고 아래쪽만 늘거나 줄어듭니다.

### 본 화면 표와 도구 줄

- **[제거]** 실시간·시간 변경 탭 표의 `순서` 열(끌기 손잡이)과 `삭제` 열을 없앴습니다. 순서와 삭제는 `시간대 관리` 창의 `그룹 목록`에서 합니다.
- **[제거]** 본 화면의 `기준` 표시를 없앴습니다. `기준`이라는 표기는 `시간대 관리` 창에서만 보입니다.
- **[개선]** 표 도구 버튼 이름을 `이미지 저장`·`클립보드에 복사`로 바꿨습니다(영어: Save Image, Copy to Clipboard).

### 고정 시간

- **[제거]** `고정 날짜` 입력칸과 달력 버튼을 없앴습니다. 예전에 저장한 고정 날짜는 쓰지 않습니다.
- **[개선]** 탭을 연 날(기준 시간대 기준 오늘)로 슬롯 시각을 계산합니다. 서머타임 표시와 시간대 약어·UTC 시차도 그 날짜를 따르고, 탭을 다시 열면 그때 날짜로 다시 맞춥니다.
- **[수정]** `실시간 표시`가 꺼져 있을 때 `표준시 (UTC)` 타일로 UTC 행을 다시 켜거나 도시를 추가하면, 열어 둔 타임라인에도 바로 나옵니다.
- **[수정]** `실시간 표시`가 꺼져 있을 때 1번 슬롯 시각을 고치거나 타임라인에서 슬롯을 끌거나 맨 위 시간대를 바꾸면, `복사 미리보기`가 바로 바뀝니다.

### 화면 용어와 다듬기

- **[개선]** 한국어 화면에서 섞여 쓰이던 `타임존`을 `시간대`로 통일했습니다(`시간대 프리셋`, 그룹 설정의 `시간대` 이름표 등).
- **[개선]** 사이드바 제목 아래의 버전 표기를 오른쪽 정렬했습니다.
- **[개선]** 도움말의 시간대 관리·기준 설명을 지금 화면에 맞게 고쳤습니다("맨 위 시간대").
