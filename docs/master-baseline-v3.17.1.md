## 직전 안정 버전 이후 추가·개선된 기능

항목 앞의 분류: **추가** 새 기능, **개선** 기존 기능의 개선(다른 기능과 합친 경우 포함), **수정** 제공하던 기능의 버그 수정, **제거** 제공하던 기능의 삭제.

### 그룹 설정 창

- **개선** 선택한 그룹 탭에는 이름과 설정(⚙) 버튼만 둡니다. 설정 버튼을 누르면 그 그룹의 설정 창이 열리고, 창 제목에 그룹 이름이 보입니다.
- **개선** 그룹 설정 창에서 다음을 합니다.
  - 이름 변경: 입력칸 옆 `변경` 버튼을 눌러야 저장됩니다.
  - 그룹 내보내기·가져오기
  - 기준 시간
  - 낮/밤 시간
  - 그룹 삭제(확인 창)
- **개선** 창은 닫기 버튼, 바깥 클릭, Esc로 닫습니다.
- **개선** 기준 시간과 낮/밤 시간 선택은 본 화면에서 빠지고 그룹 설정 창으로 옮겼습니다.
- **추가** 낮/밤 시간은 그룹마다 따로 저장합니다. 정하지 않은 그룹은 공통 값을 씁니다. 그룹 내보내기 파일에는 그 그룹의 값이 들어가고, 전체 설정 내보내기에는 공통 값이 들어갑니다.

### 타임존 추가

- **개선** 본 화면의 도시 선택 콤보박스를 없앴습니다. 도구 줄 맨 앞에 `타임존 추가` 이름표와 `목록` 버튼을 둡니다.
- **개선** `목록`을 누르면 `타임존 추가` 창이 열립니다. 창에는 두 탭이 있습니다.
  - `타임존 프리셋`: 먼저 열리는 탭입니다. 도시 목록을 도시·약어·UTC 오프셋으로 검색해 추가합니다. 첫 타일 `표준시 (UTC)`를 누르면 숨긴 UTC 행을 다시 표시하고, 이미 보이면 안내만 합니다.
  - `사용자 커스텀`: 약어·이름·UTC 시차를 넣어 고정 시차 항목을 추가합니다. 추가하면 창이 닫힙니다. 창을 닫으면 입력하던 내용은 지워집니다.
- **개선** 창은 닫기 버튼과 Esc로 닫습니다. 화면 안 입력·확인 창이 위에 있으면 그 창이 먼저 닫힙니다.
- **수정** 같은 도시나 같은 약어를 다시 추가하면 "이미 존재합니다" 안내가 뜹니다.
- **수정** 예전 표준시 목록에서 추가한 시차 항목은 그동안 저장만 되고 표에 나오지 않았고, 다시 열면 사라졌습니다. 이제 이런 항목은 불러올 때 고정 시차 항목(`UTC+09:00 표준시` 등)으로 바뀌어 표에 나오고 그 시차로 계산됩니다. 이름의 `표준시`는 화면 언어를 따릅니다.

### 도구 줄

- **개선** 예전 첫째 줄(타임존·커스텀)과 둘째 줄(표기 / 복사 양식 등)을 한 줄로 합쳤습니다.
- **개선** `이미지 저장`은 `이미지`, `전체 복사`는 `복사`로 이름을 줄였습니다. 마우스를 올리면 전체 뜻이 안내됩니다.
- **개선** 고정 시간 탭은 다음과 같이 다듬었습니다.
  - 슬롯 수 칸을 한 자리 숫자에 맞게 좁혔습니다.
  - 고정 날짜(날짜 선택 버튼) 뒤에 구분선을 넣었습니다.
  - `실시간 표시` 글자를 다른 이름표와 같은 형식으로 맞췄습니다.

### 계산기

- **수정** 기간 계산과 날짜 이동 계산에서 날짜 입력칸과 달력 버튼이 항상 한 줄입니다.
- **수정** 기간 계산은 시작일·달력·바꾸기·종료일·달력이 한 줄입니다. 카드가 좁아 날짜가 잘릴 만큼이면 종료일만 다음 줄로 내려갑니다.
- **수정** 날짜 이동 계산의 단위·방향 선택칸은 가장 긴 항목이 보이는 너비를 지킵니다. 숫자 칸 옆에 자리가 모자라면 함께 다음 줄로 내려갑니다.

### 화면 다듬기

- **개선** 사이드바 제목·버전과 기능 메뉴 사이에 구분선을 넣었습니다.
- **수정** 버튼에 마우스를 올려 툴팁을 본 뒤 그 버튼으로 연 창을 닫아도, 툴팁이나 버튼 강조가 화면에 남지 않습니다.
- **개선** 초점으로 뜨는 툴팁은 Tab 키로 이동했을 때만 나옵니다.
- **개선** 도움말의 시간대 그룹·시간대 추가·복사 설명을 지금 화면에 맞게 고쳤습니다.
