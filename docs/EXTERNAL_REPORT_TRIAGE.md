# 외부 리포트 검토 결과

- 검토일: 2026-04-02
- 검토 기준 버전: 3.12.1
- 원본 리포트 작성일: 2026-03-31
- 원본 리포트 기준 버전: 3.11.9

이 문서는 외부 이슈 제보를 현재 코드베이스 상태에 맞춰 다시 정리한 결과입니다. 원본 리포트의 일부 항목은 이미 수정되었고, 일부는 구버전 기준이라 최신 상태와 맞지 않았으며, 일부는 제품 의도에 따라 유지하기로 한 항목입니다.

## 상태 기준

- `완료`: 현재 워크스페이스 기준으로 대응이 끝난 항목
- `종료`: 리포트가 구버전 기준이거나 현재 동작이 의도된 스펙이라 추가 작업을 하지 않는 항목

## 완료

### [중-1] 그룹/보조 그룹 이름 입력의 브라우저 `prompt()` 제거

- 상태: `완료`
- 결과:
  - 그룹 및 보조 그룹 이름 입력이 주입 가능한 `promptFn` 기반으로 동작합니다.
  - 브라우저 기본 다이얼로그 대신 앱 내부 프롬프트 오버레이를 사용합니다.

### [중-2] `index.html`의 190개 이상 개별 스크립트 태그 제거

- 상태: `완료`
- 결과:
  - `index.html`은 이제 190개 이상의 개별 스크립트 태그 대신 단일 소스 로더만 로드합니다.
  - `script_list.tmp`가 소스 스크립트 순서의 기준 파일입니다.
  - `js/source-script-loader.js`는 이 목록에서 생성됩니다.
  - 로더와 스크립트 목록이 어긋나면 빌드와 테스트가 즉시 실패합니다.
- 메모:
  - 배포 출력은 이 변경 전에도 이미 번들링되고 있었습니다.
  - 이번 변경은 소스 모드에서 HTML 수동 관리 지점을 제거하는 데 목적이 있습니다.

### [중-3] 전체 시간대 오버레이의 실시간 검색 필터 추가

- 상태: `완료`
- 결과:
  - 전체 시간대 오버레이 상단에 검색 입력창이 추가되었습니다.
  - 시간대 이름, 도시 라벨, 약어, UTC 오프셋 라벨로 필터링할 수 있습니다.
  - 초기화 버튼과 빈 결과 상태도 함께 추가했습니다.

### [중-4] Branch coverage threshold 69.3% 지적

- 상태: `완료`
- 결과:
  - 검토 시점에는 이미 구버전 정보였습니다.
  - 현재 `vite.config.js`는 `branches: 72.0`을 사용합니다.
  - 로컬 coverage는 설정된 threshold를 초과해 통과합니다.

### [중-5] `calculator.js`의 브라우저 의존 날짜 파싱 제거

- 상태: `완료`
- 결과:
  - 사용자 입력 경로에서 브라우저 의존적인 `new Date(raw)` fallback 파싱을 제거했습니다.
  - 계산기 파싱은 명시된 포맷만 허용하도록 정리했습니다.
  - 카운트다운 대상값 파싱과 Unix 변환기 파싱을 강화하고 회귀 테스트를 추가했습니다.

### [하-1] CRLF/LF 줄바꿈 정규화

- 상태: `완료`
- 결과:
  - `.gitattributes`의 LF 정책은 이미 존재했습니다.
  - 작업트리에 남아 있던 `w/mixed` 파일을 선언된 줄바꿈 정책에 맞게 정규화했습니다.
  - Windows PowerShell 래퍼는 선언된 정책에 맞춰 CRLF로 복원했습니다.

### [하-2] PowerShell 전용 빌드 경로 제거

- 상태: `완료`
- 결과:
  - 빌드 패키징은 이제 Node 기반 스크립트로 실행됩니다.
  - `npm run build`와 `npm run build:strict`는 크로스플랫폼으로 동작합니다.
  - `build_extension.ps1`은 호환성을 위한 얇은 Windows 래퍼로만 남습니다.

### [하-3] 아키텍처 문서 추가

- 상태: `완료`
- 결과:
  - `docs/ARCHITECTURE.md`를 추가했습니다.
  - 부트스트랩 흐름, 조립 계층, UI 런타임 책임, 빌드 모델을 문서화했습니다.
