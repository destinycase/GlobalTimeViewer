# 용어 사전

Global Time Viewer의 화면·기능·시간 개념·배포 용어를 한곳에 모았습니다. 개선 요청이나 문의를 할 때 아래 이름을 쓰면 어느 부분을 말하는지 정확히 전달할 수 있습니다. 화면 이름은 한국어 화면 기준이며 괄호 안은 영어 화면 이름입니다. 이 문서는 **1차 안정 버전 v3.12.10** 기준입니다.

## 화면과 메뉴

| 용어 | 뜻 |
| --- | --- |
| 실시간 (Realtime) | 추가한 지역의 현재 날짜와 시각이 계속 갱신되는 화면 |
| 시간 변경 (Time Edit) | 기준 날짜·시각을 직접 입력하거나 조정해 각 지역의 대응 시각을 비교하는 화면 |
| 연속 시간 변경 (Continuous Time Edit) | 시작·끝 시각이 있는 여러 구간을 나란히 비교하는 화면 |
| 고정 시간 (Fixed Time) | 지정한 날짜에서 여러 시각(슬롯)을 시간대별로 표와 타임라인으로 보는 화면 |
| 계산기 도구 (Calculator) | 시간 단위 변환, 기간 계산, 날짜 이동 계산, 카운트다운, 시간 포맷 변환기를 모은 화면 |
| 시간대 표 | 각 화면 가운데의 표. 행 하나가 지역(시간대) 하나입니다. 열은 순서·시간대·이름·UTC·시간·복사·제거 등입니다. |
| 타임라인 보기 (Timeline View) | 시간대 표 위에 하루의 흐름을 막대로 보여 주고 표시선을 끌어 시각을 조정하는 보기 |
| 표시선(인디케이터) | 타임라인 위의 세로선. 끌어서 시각을 바꾸며, 고정 시간 탭의 `실시간 표시` 선은 현재 시각을 따라 움직이고 끌 수 없습니다. |
| 표기 / 복사 양식 (Display / Copy Format) | 시간대 표에 보일 항목과 텍스트 복사에 넣을 항목, 그 순서를 정하는 설정 |
| 항목 (Parts) | 시간 열에 보일 세부 요소(낮/밤, 날짜, 시간, 요일) |
| 복사 미리보기 (Copy Preview) | 현재 양식으로 복사될 텍스트를 미리 보여 주는 영역 |
| 토스트 | 화면 아래에 잠깐 나타나는 결과 안내(복사 완료, 저장 실패 등) |
| 치명 오류 화면 | 앱을 시작하지 못했을 때 나타나는 화면. 오류 코드, `재시도`, `전체 초기화`를 제공합니다. |

## 지역과 그룹

| 용어 | 뜻 |
| --- | --- |
| 그룹 | 시간대 모음 하나. 화면 위쪽 탭으로 전환하며 최소 1개가 필요합니다. 기본 이름은 `그룹`입니다. |
| 보조 그룹 (Aux Group) | 그룹 안에서 시간대 구성을 한 번 더 나누는 하위 모음. 그룹·보조 그룹 단위로 내보내기/가져오기를 할 수 있습니다. |
| 기준 시간 (Base Time) | 시간 변경·연속 시간 변경에서 입력 시각의 기준이 되는 지역. 시간대 표에서 순서 칸에 `기준`으로 표시됩니다. |
| 표준 시간대 | 목록에서 고른 실제 지역 시간대(IANA 시간대, 예: `Asia/Seoul`). 서머타임 규칙을 자동으로 따릅니다. |
| 커스텀 시간대 (Custom) | 약어·이름과 UTC 시차를 직접 입력해 만든 시간대. 입력한 고정 시차만 사용하며 서머타임을 따르지 않습니다. |
| 시간대 목록 | `목록(List)` 버튼으로 여는 창. `표준시 목록`과 `국가 - 지역 목록`에서 검색해 추가합니다. |
| 낮/밤 | 각 지역 시각이 낮 시작~밤 시작 사이인지 표시하는 항목(☀️/🌙). 기준 시각은 설정에서 바꿀 수 있습니다. |

## 시간 개념

| 용어 | 뜻 |
| --- | --- |
| UTC | 세계 표준시. 각 지역 시각은 UTC와의 차이(시차, 오프셋)로 표시합니다. 예: 한국 `UTC +09:00` |
| 오프셋(시차) | UTC와의 시간 차이. UTC보다 빠르면 `+`, 늦으면 `-`입니다. |
| 서머타임(DST) | 계절에 따라 시계를 앞당기는 제도. 해당 기간의 지역명에는 표에서만 `[DST]`가 붙고 복사 텍스트에는 붙지 않습니다. |
| 슬롯 | 고정 시간 화면에서 비교할 시각 하나. `+ 슬롯 추가`로 늘립니다. |
| 고정 날짜 | 고정 시간 화면에서 슬롯 시각을 계산할 날짜 |
| 구간 | 연속 시간 변경 화면의 시작~끝 시각 한 묶음. 최대 12개입니다. |
| 추가 시간 (Extra Time) | 시간 변경 화면에서 끝 시각을 함께 보여 주는 옵션. 켜면 `시작 시간`/`끝 시간`으로 표시합니다. |
| 기간 / 일수 | 두 시각 사이의 길이 / 날짜 차이 |
| Unix 타임스탬프 | 1970-01-01 00:00:00 UTC부터 지난 초(또는 밀리초) 수 |

## 저장과 설정

| 용어 | 뜻 |
| --- | --- |
| 저장 데이터 | 그룹·시간대·양식 등 설정. 이 확장 프로그램 전용 브라우저 저장공간(localStorage)에 자동으로 보관됩니다. |
| 전체 내보내기 / 전체 가져오기 (Export All / Import All) | 모든 설정을 JSON 파일로 백업 / 복원 |
| 설정만 초기화 (Reset Settings Only) | 그룹과 시간대는 남기고 나머지 설정을 기본값으로 되돌림 |
| 전체 초기화 (Reset All) | 저장된 설정을 모두 지움. 되돌릴 수 없으므로 먼저 내보내기를 권장합니다. |
| 테마 / 언어 / 화면 크기 | 다크·라이트, 한국어·영어, 50~200% 배율. 각각 따로 저장됩니다. |

## 버전과 배포

| 용어 | 뜻 |
| --- | --- |
| 제품 버전 | `주.부.패치` 형식(예: 3.12.10). 동작이 바뀔 때마다 패치 숫자가 1씩 오릅니다. |
| 안정 버전(기준판) | 웹 스토어 제출 기준으로 고정한 버전. 기준 태그(`vX.Y.Z`)와 [기준판 문서](master-baseline-v3.12.10.md)로 보존합니다. 안정 버전 지정과 실제 스토어 게시는 별개입니다. |
| 배포 ZIP | 웹 스토어에 올리거나 직접 설치할 때 쓰는 압축 파일 `gtv-vX.Y.Z.zip` |
| SHA-256 | 파일 내용으로 계산한 고유 지문. 기준판 문서의 값과 같으면 같은 파일입니다. |
| 압축 해제 설치 | `chrome://extensions`에서 개발자 모드를 켜고 압축을 푼 폴더(`manifest.json`이 있는 폴더)를 불러오는 설치 방법 |
| 개발 이력 | 버전별 기능 변경 기록([development-history.md](development-history.md)) |

## 문의 예시

- "고정 시간 화면에서 슬롯 표시선을 끌 때 복사 미리보기가 늦게 바뀝니다."
- "보조 그룹 가져오기를 하면 기준 시간이 바뀝니다."
- "표기 / 복사 양식에서 요일 항목을 끄면 연속 시간 변경 표에도 반영되었으면 합니다."
- "v3.12.10 배포 ZIP의 SHA-256이 기준판 문서와 다릅니다."
