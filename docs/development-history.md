# 개발 히스토리

세계 시계·시간 변경·고정 시간·계산기·복사/이미지 저장·설정 저장 등 제품의 기능 추가·개선·제거와 사용자에게 영향을 주는 동작 변경을 버전별로 기록합니다. 웹 스토어 제출 기준이 되는 안정 버전은 기능 변경이 없어도 지정 사실과 기준판 문서 링크를 남깁니다. 안정 버전 지정이 실제 스토어 제출·게시 완료를 뜻하지는 않습니다. 코드 구조 정리(리팩터링)도 해당 버전에 **구조 정리** 항목으로 적습니다. 구조 정리는 화면과 동작을 바꾸지 않습니다. 검증·문서 정리·배포 파일 생성 기록은 적지 않으며, 기능 변경과 구조 정리가 모두 없는 버전은 생략합니다. 과거 항목은 당시 동작을 설명합니다. 현재 사용법은 [사용자 가이드](user-guide.md), 구조와 구현은 [개발자 가이드](developer-guide.md)를 참고하세요.

현재 안정 기준판은 [v3.14.1 · 3차 안정 버전](master-baseline-v3.14.1.md)이고, 이전 기준판은 [v3.13.1 · 2차 안정 버전](master-baseline-v3.13.1.md), [v3.12.10 · 1차 안정 버전](master-baseline-v3.12.10.md)입니다.

## v3.14.3

- 시간 포맷 변환기 칸에 손으로 한 글자씩 입력하면 첫 글자부터 "유효하지 않은 날짜"로 덮어써져 입력할 수 없던 문제를 고쳤습니다. 입력 중인 칸은 그대로 두고 나머지 칸만 갱신하며, 칸을 벗어나면 올바른 값을 표준 형식으로 정리합니다.
- 카운트다운에서 달력으로 목표 시각을 고른 뒤 칸을 직접 고치면 무시되고 되돌아가던 문제를 고쳤습니다.
- 서머타임이 시작되며 건너뛰는 시각(예: 뉴욕 02:30)을 입력하면 안내 없이 1시간 이른 시각이 되던 문제를 고쳤습니다. 이제 건너뛴 만큼 뒤(03:30)로 맞추고 안내를 표시합니다.
- 고정 시간 표 칸에 25:00:00, 10:75:00처럼 범위 밖 시각을 넣으면 23:00, 10:59로 조용히 바꾸던 동작을 다른 시간 입력과 같이 오류 안내로 거부하도록 바꿨습니다.
- 시간 포맷 변환기의 ISO 8601 칸은 `YYYY-MM-DD`, `YYYY-MM-DDTHH:mm[:ss]`(시간대 선택)만 받습니다. 주·연중일 표기, 구분자 없는 형식, 24:00처럼 드문 표기는 유효하지 않은 날짜로 표시합니다.
- 시간대 목록의 `표준시 목록` 탭에 UTC 오프셋 검색용 안내 문구를 따로 두고, 도시 등으로 찾지 못하면 `국가 - 지역 목록`에서 검색하라고 안내합니다.
- 구조 정리: 계산기 날짜 해석에서 숫자 0(1970-01-01)과 0~99년 로컬 날짜를 올바르게 처리하도록 정리했습니다(화면 동작 변화 없음).

## v3.14.2

- 시간 변경·연속 시간 변경 표의 지역별 기간이 서머타임이 바뀌는 시각을 걸치면 1시간 틀리던 문제를 고쳤습니다(예: 뉴욕 서머타임 종료 시 실제 2분이 -58분으로 표시). 이제 모든 행이 실제 경과 시간을 보이며, 텍스트 복사와 이미지 저장의 기간도 같습니다.
- 시간 포맷 변환기의 ISO 8601·RFC 2822 칸에 2023-02-29처럼 없는 날짜를 넣으면 다음 달 날짜로 바꿔 변환하던 문제를 고쳤습니다. 이제 "유효하지 않은 날짜"로 표시합니다.
- 날짜 이동 계산의 이동량에 2.5처럼 정수가 아닌 값이나 0을 넣으면 정수 부분만 쓰던 문제를 고쳤습니다. 이제 결과를 비우고 "1 이상의 정수를 입력하세요" 안내를 표시합니다.

## v3.13.4

- 고정 시간 탭의 시간대 약어(예: PDT/PST)를 오늘 날짜가 아니라 고정 날짜 기준으로 표시합니다. 이전에는 UTC 시차와 각 시각 옆 `DST` 표시는 고정 날짜를 따르는데 약어만 오늘 기준이어서 서로 어긋날 수 있었습니다.

## v3.13.3

- 텍스트 복사와 이미지 저장에도 서머타임인 시각 뒤에 `DST`가 들어갑니다.
- `표기 / 복사 양식`의 시간 항목에 `서머타임`을 추가해 표시와 복사에서 따로 켜고 끌 수 있습니다(기본 켜짐). 이전 설정을 불러오면 켜진 상태로 시작합니다.

## v3.13.2

- 저장 데이터에 갱신 번호와 시각을 함께 기록하고, 저장소 후보가 여럿이면 가장 최근 것을 복원하도록 했습니다. (확장에 `storage` 권한이 없어 실제 저장 위치는 계속 `localStorage` 하나입니다.)
- 표를 다시 그릴 때 이전 날짜 선택기를 정리해 오래 사용할 때 느려질 가능성을 줄였습니다.

## v3.11.3

- 계산기의 날짜 이동을 UTC 기준으로 계산해 시간대에 따라 날짜가 밀리지 않습니다.
- 월·연 이동 결과가 없는 날짜면 그 달의 말일로 맞춥니다. 예: 2026-01-31 + 1개월 = 2026-02-28, 2024-02-29 + 1년 = 2025-02-28.
- 날짜 선택기에서 31일이 선택된 상태로 이전/다음 달로 이동할 때 달을 건너뛰던 문제를 고쳤습니다.

## v3.11.1

- 사용자 지정 시간대의 약어 표시를 표준 시간대와 다른 색으로 구분합니다.
- 같은 그룹에 같은 약어의 사용자 지정 시간대나 같은 표준 시간대를 다시 추가하면 안내를 표시하고 추가하지 않습니다.
- `[DST]` 표시는 표의 지역명에만 붙이고 복사·내보내기 텍스트에는 넣지 않습니다.
- 시간대 목록에서 서머타임 지역이 중복으로 보이지 않으며, 추가하면 고정 시차가 아니라 서머타임 규칙을 따르는 시간대로 저장합니다.

## v3.10.2

- 사용자 지정 시간대에 입력한 UTC 시차가 반영되지 않고 0으로 처리되던 문제를 고쳤습니다.
- 고정 시간 탭 시간대 표에서 행을 끌어 순서를 바꾸는 기능을 없앴습니다.

## v3.10.1

- 시간 변경과 연속 시간 변경의 시간 조정이 기준 시간대가 아니라 UTC 기준으로 적용되던 문제를 고쳤습니다.
- 고정 시간 표의 슬롯 머리글 제목을 칸 가운데에 맞추고 글자를 키웠습니다.

## v3.9.3

- 계산기의 Unix 타임스탬프 변환기를 `Smart Format Converter`로 바꿨습니다. Unix(초/밀리초), ISO 8601(현지/UTC), RFC 2822, SQL, 읽기 쉬운 형식을 지원하며 한 칸을 고치면 나머지가 함께 바뀝니다. `Now` 버튼과 형식별 복사 버튼이 있습니다.
- 왼쪽 메뉴 순서를 `실시간 > 시간 변경 > 연속 시간 변경 > 고정 시간 > 계산기 도구`로 정리하고 고정 시간과 계산기 도구 사이에 구분선을 넣었습니다.
- 고정 시간 탭에서 사라졌던 슬롯 개수 조절을 되살렸습니다.

## v3.9.2

- 타임라인 표시선을 끌 때 끊기거나 놓치던 현상을 줄이고, 라벨뿐 아니라 선 자체도 끌 수 있게 잡는 영역을 넓혔습니다. 끌 수 있는 곳에서만 좌우 화살표 커서가 나타납니다.
- 시간 변경 탭 타임라인 표시선에 `시간` 또는 `시작 시간`/`끝 시간` 라벨을 표시하고, 패널 위쪽의 같은 제목은 없앴습니다.
- 연속 시간 변경과 고정 시간 탭에서 `표기 / 복사 양식`의 날짜·시간 체크가 표에 바로 반영되도록 고쳤습니다.
- 고정 시간 슬롯 시간 입력 칸 너비를 100px로 조정했습니다.
