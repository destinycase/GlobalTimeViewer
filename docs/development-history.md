# 개발 히스토리

세계 시계·시간 변경·고정 시간·계산기·복사/이미지 저장·설정 저장 등 제품의 기능 추가·개선·제거와 사용자에게 영향을 주는 동작 변경을 버전별로 기록합니다. 웹 스토어 제출 기준이 되는 안정 버전은 기능 변경이 없어도 지정 사실과 기준판 문서 링크를 남깁니다. 안정 버전 지정이 실제 스토어 제출·게시 완료를 뜻하지는 않습니다. 코드 구조 정리(리팩터링)도 해당 버전에 **구조 정리** 항목으로 적습니다. 구조 정리는 화면과 동작을 바꾸지 않습니다. 검증·문서 정리·배포 파일 생성 기록은 적지 않으며, 기능 변경과 구조 정리가 모두 없는 버전은 생략합니다. 과거 항목은 당시 동작을 설명합니다. 현재 사용법은 [사용자 가이드](user-guide.md), 구조와 구현은 [개발자 가이드](developer-guide.md)를 참고하세요.

각 항목 앞에는 분류를 붙입니다: **[추가]** 새 기능, **[개선]** 기존 기능의 개선(다른 기능과 합친 경우 포함), **[수정]** 제공하던 기능의 버그 수정, **[제거]** 제공하던 기능의 삭제, **[구조 정리]** 화면과 동작을 바꾸지 않는 코드 정리. 안정 버전 지정 항목에는 분류를 붙이지 않습니다.

현재 안정 기준판은 [v3.17.1 · 6차 안정 버전](master-baseline-v3.17.1.md)이고, 이전 기준판은 [v3.16.1 · 5차 안정 버전](master-baseline-v3.16.1.md), [v3.15.1 · 4차 안정 버전](master-baseline-v3.15.1.md), [v3.14.1 · 3차 안정 버전](master-baseline-v3.14.1.md), [v3.13.1 · 2차 안정 버전](master-baseline-v3.13.1.md), [v3.12.10 · 1차 안정 버전](master-baseline-v3.12.10.md)입니다.
