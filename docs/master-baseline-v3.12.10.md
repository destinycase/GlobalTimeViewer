## 갖춘 기능

### 시간 비교 화면

- **실시간**: 추가한 지역의 날짜·시각·UTC 시차·낮/밤을 한 표에서 계속 갱신해 보여 줍니다. 서머타임 중인 지역은 표의 지역명에 `[DST]`를 표시합니다.
- **시간 변경**: 기준 지역의 날짜·시각을 입력하거나 `지금 시간`, `0시`, `정각`, ±1시간·±1일·±1주·±4주 버튼으로 조정하면 모든 지역의 대응 시각이 바뀝니다. `추가 시간 표시`를 켜면 끝 시각도 함께 비교합니다.
- **연속 시간 변경**: 시작·끝 시각이 있는 구간을 최대 12개까지 만들어 나란히 비교합니다. 구간 일괄 조정, 이전 구간 끝 가져오기, 구간 접기/펼치기, 시작·끝 시간 조정 일괄 켜기/끄기를 지원합니다.
- **고정 시간**: 지정한 날짜에서 여러 슬롯 시각을 시간대별 표와 타임라인으로 봅니다. 현재 시각을 따라 움직이는 `실시간 표시` 선을 켤 수 있고, 슬롯 표시선을 끌어 옮기는 동안 슬롯 시각과 복사 미리보기가 함께 갱신되며 놓을 때 저장합니다.
- **타임라인 보기**: 실시간·시간 변경·고정 시간 화면에서 하루의 흐름을 막대로 보여 주며, 표시선을 끌어 시각을 조정합니다.

### 지역과 그룹

- 표준 시간대를 도시·시간대 이름·약어·UTC 시차로 검색해 추가합니다(`표준시 목록`, `국가 - 지역 목록`). 서머타임 지역은 규칙을 따르는 시간대로 저장합니다.
- 약어·이름·UTC 시차를 입력해 커스텀 시간대를 만들며, 표준 시간대와 다른 색으로 구분합니다.
- 같은 그룹에 같은 시간대나 같은 약어의 커스텀 시간대를 다시 추가하지 않도록 막습니다.
- 그룹과 보조 그룹으로 시간대 모음을 나누고, 이름 변경·삭제·행 순서 변경을 지원합니다. 기준 시간 행은 `기준`으로 표시합니다.

### 복사·이미지·양식

- 행별 복사, `전체 복사`, 구간 복사를 지원하며 결과를 토스트로 알립니다.
- 시간대 표와 구간을 이미지로 저장합니다.
- `표기 / 복사 양식`에서 표와 복사 텍스트에 넣을 항목(시간대·이름·UTC·시간·일수·기간)과 시간 세부 항목(낮/밤·날짜·시간·요일), 순서를 정하고 복사 미리보기로 확인합니다. 설정은 탭 공통으로 저장됩니다.

### 계산기 도구

- 시간 단위 변환(일·시간·분·초).
- 기간 계산: 시작일·종료일 사이의 기간(음수 포함)과 총 일수·시간·분·초. 시작일·종료일 바꾸기를 지원합니다.
- 날짜 이동 계산: 일·주·개월·년 단위로 더하거나 빼며, 없는 날짜는 그 달의 말일로 맞춥니다.
- 카운트다운: 목표 시각까지 남은 시간을 표시하고 시작·중지·초기화합니다.
- 시간 포맷 변환기: Unix(초/밀리초), ISO 8601(로컬/UTC), RFC 2822, SQL, 읽기 쉬운 형식을 서로 실시간으로 변환하고 형식별로 복사합니다.
- 날짜 입력은 `YYYY-MM-DD` 형식을 검증하며 존재하지 않는 날짜와 범위를 벗어난 시각을 거부하고 입력 예시와 안내를 보여 줍니다. 달력 선택기를 제공합니다.

### 저장·설정·화면

- 설정을 이 확장 프로그램 전용 브라우저 저장공간(localStorage)에 자동 저장합니다. 이전 버전이 남긴 저장 데이터 중 v3.2.1~v3.2.3 형식의 저장 키는 자동으로 이어받습니다.
- 전체·그룹·보조 그룹 단위로 설정을 JSON 파일로 내보내고 가져옵니다. 형식이 맞지 않는 파일은 거부하고 기존 데이터를 보존합니다.
- `설정만 초기화`(그룹·시간대 유지)와 `전체 초기화`를 제공합니다.
- 한국어·영어, 다크·라이트 테마, 50~200% 화면 크기, 낮/밤 시작 시각을 설정합니다.
- 시작에 실패하면 오류 코드와 `재시도`, 오류 코드 복사를 제공하는 오류 화면을 보여 줍니다. 확장 아이콘으로 새 탭을 열지 못하면 아이콘에 실패 표시를 잠시 띄웁니다.
