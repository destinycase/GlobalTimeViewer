# Global Time Viewer 사용자 가이드

이 안내서는 프로그램을 개발하지 않는 사용자를 위한 설명이며, **6차 안정 버전 v3.17.1** 기준으로 작성했습니다. 화면의 일부 버튼 이름은 선택한 언어에 따라 한국어 또는 영어로 표시될 수 있습니다.

## 설치와 시작

1. [Chrome 웹 스토어의 Global Time Viewer 페이지](https://chromewebstore.google.com/detail/ojmkgfaeececindhbegihnonpndkbnho)를 엽니다.
2. Chrome에 추가한 뒤 확장 프로그램을 실행합니다. 확장 프로그램이 새 탭에서 열립니다.
3. 처음 실행하면 실시간 세계 시계 화면이 표시됩니다. 저장된 설정이 있으면 다음 실행에도 이어집니다.

## 화면 구성

왼쪽 메뉴에서 필요한 작업을 선택합니다.

| 메뉴 | 하는 일 |
| --- | --- |
| 실시간 (Realtime) | 여러 지역의 현재 시각을 한 표에서 비교합니다. |
| 시간 변경 (Time Edit) | 기준 날짜와 시간을 바꿔 각 지역의 대응 시각을 확인합니다. |
| 연속 시간 변경 (Continuous Time Edit) | 시작/종료 시각이 있는 여러 시간 구간을 나란히 비교합니다. |
| 고정 시간 (Fixed Time) | 지정한 날짜의 시간대별 시각을 표나 타임라인으로 봅니다. |
| 계산기 도구 (Calculator) | 기간, 시간 이동, 카운트다운, Unix 시간 등 시간 관련 계산을 합니다. |

왼쪽 아래의 ⚙️ **설정** 버튼은 설정 창을, ❓ **도움말** 버튼은 짧은 사용 안내 창을 엽니다. 화면 크기, 어두운/밝은 테마, 한국어/영어는 설정 창에서 바꿉니다. 화면의 `i` 아이콘이나 버튼에 마우스를 올리거나 Tab 키로 이동하면 설명을 볼 수 있습니다.

## 지역 시계 추가와 관리

### 목록에서 지역 선택

1. 위쪽 도구 줄 맨 앞의 `타임존 추가` 옆 `목록`을 누릅니다. `타임존 추가` 창이 열립니다.
2. `타임존 프리셋` 탭의 검색 칸에 도시명, 시간대 이름, 약어 또는 UTC 오프셋을 입력합니다.
3. 원하는 지역을 선택해 현재 시계 그룹에 추가합니다. 첫 타일 `표준시 (UTC)`는 숨긴 UTC 행을 다시 표시합니다. 창은 닫기 버튼이나 Esc로 닫습니다.

### 사용자 지정 시간대 추가

1. `목록`을 눌러 연 `타임존 추가` 창에서 `사용자 커스텀` 탭을 고릅니다.
2. 약어와 이름을 입력하고 UTC 기준 시차의 시와 분을 선택합니다.
3. `추가`를 누르면 현재 그룹에 추가되고 창이 닫힙니다. 창을 닫으면 입력하던 내용은 지워집니다.

사용자 지정 항목은 입력한 UTC 오프셋을 기준으로 표시됩니다. 지역의 서머타임 규칙을 자동으로 따라야 한다면 사용자 지정 오프셋 대신 목록에서 해당 도시/시간대를 선택하세요. 오프셋은 UTC보다 빠른 시간이 `+`, 늦은 시간이 `-`입니다. 예를 들어 UTC+9는 한국 표준시와 같은 고정 오프셋입니다.

### 기본 시각과 시계 그룹

- 위쪽의 그룹 탭은 서로 다른 시간대 모음을 관리합니다. `+`로 그룹을 추가하고, 필요한 경우 표의 지역 순서를 조정하거나 항목을 제거합니다. 그룹 이름은 앱 안의 입력 창에서 정합니다. 선택한 그룹은 왼쪽 기능 탭을 바꿔도 그대로 유지됩니다.
- 선택한 그룹 탭에는 이름과 설정(⚙) 버튼이 있습니다. 설정 버튼을 누르면 그 그룹의 설정 창이 열리고, 아래 항목을 바꿀 수 있습니다. 창은 닫기 버튼, 바깥 클릭, Esc로 닫힙니다.
  - **그룹 이름**: 입력칸에 새 이름을 쓰고 옆의 `변경` 버튼을 누르면 저장됩니다. 버튼을 누르지 않고 닫으면 이름은 바뀌지 않습니다.
  - **내보내기 / 가져오기**: 이 그룹의 시간대와 설정을 파일로 저장하거나 파일에서 불러옵니다. 전체 설정 백업과는 범위가 다릅니다.
  - **기준 시간**: 표의 기준 지역을 선택합니다. 시간 변경 화면에서 입력한 기준 시각을 다른 지역과 비교할 수 있습니다.
  - **낮/밤 시간**: 낮 시작·밤 시작 시각을 정합니다. 그룹마다 따로 저장되며, 정하지 않은 그룹은 공통 값을 씁니다.
  - **그룹 삭제**: 확인 창에서 확인을 눌러야 지워집니다.
- 보조 그룹 단위의 설정 내보내기와 가져오기는 화면에 표시되는 해당 기능 버튼과 안내를 따릅니다.

서머타임이 적용되는 도시는 그 시각이 서머타임 기간이면 시각 옆에 `DST`가 표시됩니다. 시작·끝처럼 시각이 여러 개면 시각마다 따로 판단하므로, 서머타임이 끝나는 날을 걸치면 앞 시각에만 표시될 수 있습니다. 텍스트 복사와 이미지 저장에도 같은 표시가 들어갑니다. 필요 없으면 `표기 / 복사 양식`의 시간 `항목`에서 `서머타임`을 끄세요(표시와 복사를 따로 정할 수 있습니다). 사용자 지정 시차 항목에는 표시되지 않습니다. 고정 시간 탭에서는 고정 날짜를 기준으로 각 슬롯 시각에 표시하며, 시간대 약어와 UTC 시차도 고정 날짜를 따릅니다(`실시간 표시` 열은 오늘 기준).

서머타임이 시작되는 날 건너뛰는 시각(예: 뉴욕 02:30)을 입력하면 건너뛴 만큼 뒤(03:30)로 맞추고 안내가 표시됩니다. 서머타임이 끝나며 두 번 있는 시각은 첫 번째(서머타임) 시각으로 해석합니다. 고정 시간 표 칸에 25:00:00처럼 범위를 벗어난 시각이나 없는 날짜를 넣으면 오류 안내가 뜨고 값은 바뀌지 않습니다.

## 시간 비교 화면

### 실시간

추가한 지역의 날짜와 현재 시각이 행별로 갱신됩니다. 복사 열의 버튼은 해당 지역의 값을 복사하며 `복사`는 표 내용을 한 번에 복사합니다. `이미지` 버튼은 현재 표를 이미지 파일로 저장합니다. 표시/복사 형식과 타임라인 보기 옵션이 보이면 선택해 표시 방식을 조정할 수 있습니다.

### 시간 변경

기준 날짜와 시각을 입력하거나 조정하면 각 지역에서 그 순간이 몇 시인지 비교할 수 있습니다. 현재 시각 비교로 돌아가려면 실시간 메뉴를 선택하세요.

### 연속 시간 변경

시간 구간 수를 정하고 각 구간의 시작 및 종료 시각을 설정합니다. 구간을 여러 개 만들면 일정이나 근무 시간대를 비교하기 편합니다. 표시되는 최대 개수 등은 화면의 도움말 아이콘을 확인하세요.

### 고정 시간

고정 시간 항목을 추가한 뒤 날짜와 시각을 지정해 확인합니다. 필요하면 `실시간 표시` 옵션을 켜 현재 시각도 함께 표시합니다. 타임라인 보기 여부에 따라 표/시각 흐름의 표시를 전환할 수 있습니다.

## 계산기

계산기 화면에서 필요한 영역을 사용합니다. 계산 종류에 따라 결과를 복사하는 버튼이 제공됩니다.

- 단위 변환: 일, 시간, 분, 초 사이의 수량을 확인합니다.
- 기간 계산: 두 날짜/시각 사이의 차이를 계산합니다.
- 날짜/시각 이동: 기준 날짜/시각에서 지정한 양을 더하거나 뺍니다.
- 카운트다운: 목표 시각까지 남은 시간을 확인하고 필요할 때 초기화합니다.
- Unix 시간: 현재 시각 또는 입력한 타임스탬프를 여러 형식으로 확인합니다.

날짜 입력은 화면에 안내된 `YYYY-MM-DD` 형식을 사용하세요. 달력 아이콘이 있는 입력란에서는 달력 선택기를 열 수 있고, 달력으로 고른 뒤 칸을 직접 고쳐도 됩니다.

- 날짜/시각 이동의 이동량은 1 이상의 정수로 입력하세요. 2.5나 0을 넣으면 결과가 비고 안내가 표시됩니다.
- 시간 포맷 변환기에서는 아무 칸에나 직접 입력하면 나머지 칸이 바로 바뀝니다. 입력 중인 칸은 그대로 두며, 칸을 벗어나면 표준 형식으로 정리됩니다. ISO 8601 칸은 `2024-02-29`, `2024-02-29T10:30`, `2024-02-29T10:30:15+09:00`처럼 날짜, 또는 날짜와 시각(시간대 선택)을 받습니다. 2023-02-29처럼 없는 날짜나 그 밖의 표기는 "유효하지 않은 날짜"로 표시됩니다.

## 설정 백업과 초기화

왼쪽 아래의 ⚙️ **설정** 버튼을 누르면 설정 창이 열립니다. 여기서 UI 크기, 테마, 언어를 바꾸고, 전체 설정을 파일로 내보내거나 가져오고, 설정만 초기화하거나 전체 초기화합니다. 각 항목 옆에 설명이 함께 보입니다. 창은 닫기 버튼(×), 창 바깥 클릭, Esc 키로 닫습니다. 초기화를 누르면 확인 창이 뜨며, 확인을 누르면 초기화한 뒤 설정 창이 닫힙니다. 가져오기에 성공해도 설정 창이 닫힙니다.

왼쪽 아래의 ❓ **도움말** 버튼을 누르면 시간대 추가, 그룹, 기능 탭, 시각 입력, 서머타임 표시, 복사·이미지 저장, 설정과 백업을 짧게 안내하는 창이 열립니다.

설정 창의 버튼은 다음과 같습니다.

- **Export All**: 전체 설정 파일을 내려받아 백업합니다. 파일을 안전한 위치에 보관하세요.
- **Import All**: 이전에 내보낸 설정 파일을 선택해 복원합니다. 가져온 설정이 현재 데이터를 대체하거나 갱신할 수 있으므로 파일을 확인한 뒤 진행하세요.
- **Reset Settings Only**: 그룹과 시간대는 남기고 나머지 설정을 기본값으로 되돌립니다. 확인 창에서 확인을 눌러야 실행됩니다.
- **Reset All**: 전체 저장 설정을 지우는 작업입니다. 확인 창에서 확인을 눌러야 실행되며, 필요한 데이터가 있으면 먼저 내보내기 하세요.

내보내기 파일은 사용자가 직접 내려받습니다. 확장 프로그램의 설정은 브라우저 저장소에 보관됩니다. 브라우저 데이터를 지우거나 확장 프로그램을 제거하면 설정이 사라질 수 있으므로 백업을 권장합니다.

## 문제가 생겼을 때

- 지역이 표에 없으면 현재 그룹 탭을 확인하고, 지역 검색 결과에서 다시 추가하세요.
- 시간이 예상과 다르면 기준 지역, 날짜, UTC 오프셋을 확인하세요. 지역의 서머타임을 고려해야 한다면 도시 목록의 시간대를 사용하세요.
- 가져오기가 실패하면 지원되는 JSON 설정 파일인지, 파일이 손상되지 않았는지 확인한 뒤 다시 시도하세요.
- "로컬 데이터 저장에 실패했습니다. 브라우저 저장 공간이 부족합니다." 알림이 뜨면 방금 바꾼 설정이 저장되지 않은 상태입니다. 먼저 설정 창의 `Export All`로 설정을 내보내 두고, 브라우저에서 사용하지 않는 사이트 데이터를 정리한 뒤 다시 시도하세요. 저장 공간과 관계없이 "로컬 데이터 저장에 실패했습니다."만 계속 표시되면 브라우저를 다시 시작해 보세요.
- 시작 오류 화면에 오류 코드가 표시되면 코드 복사 기능을 사용해 기록하세요. 먼저 `Retry`로 다시 불러올 수 있습니다. `Reset All`은 저장된 설정을 삭제하므로 마지막 수단으로 사용하세요.
